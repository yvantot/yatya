# YATYA: Yet Another Tracker You'll Abandon

A habit tracker that lives in your new tab, the toolbar popup or a tab of its own. It's built around [PACT goals](https://nesslabs.com/smart-goals-pact): purposeful, actionable, continuous and trackable.

![YATYA](https://github.com/user-attachments/assets/d782542c-d0d3-49e9-a7fe-107debb5f603)

## Features

- Track your habits and tasks from the new tab page, the popup or a full tab.
- See stats on your progress.
- Everything is stored locally in Chrome.

## Install

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and choose this folder.

## Built with

JavaScript and the Chrome Extensions API (Manifest V3).
